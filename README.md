## 🎯 Overview

This repository contains the backend engineering projects from the **ALX Software Engineering Program**. Each project focuses on a fundamental backend concept, implemented with industry best practices.

## 📁 Projects

| Project | Description | Tech Stack | Status |
|---------|-------------|------------|--------|
| [`0x00-pagination`](0x00-pagination) | API pagination strategies | Python/Flask | ✅ Complete |
| [`0x01-caching`](0x01-caching) | Caching strategies (Redis, Memcached) | Python/Redis | ✅ Complete |
